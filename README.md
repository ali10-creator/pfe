# ROS 2 Mobile Robot – Design, Simulation and Control

## Project Overview

This project focuses on the design, development, and control of a differential-drive mobile robot using **ROS 2 Jazzy**.

The platform was developed to experiment with and compare different control strategies for mobile robotics, combining simulation and real-world implementation.

The robot is built around a Raspberry Pi 4 and uses two BLDC hoverboard motors controlled through dedicated motor drivers.

- **Robot modeling:** Mechanical design and robot description using URDF.
- **Motion control:** Implementation and comparison of PID and Sliding Mode Control (SMC).
- **Trajectory tracking:** Circular and other reference trajectory tracking.
- **Simulation:** Robot simulation and testing in Gazebo.
- **LiDAR integration:** Environment sensing using a 2D LiDAR.
- **Mapping and localization:** Integration with SLAM Toolbox.
- **Autonomous navigation:** Nav2 integration for path planning and obstacle avoidance.
- **Hardware integration:** ROS 2 communication with the Raspberry Pi and motor drivers.

## Project Objective

The main objective is to develop a flexible mobile robotic platform that can be used to test, evaluate, and compare different control techniques, while exploring the integration of perception, localization, and autonomous navigation within the ROS 2 ecosystem.
